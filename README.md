# KM — 한의학 자동 연구 기반

침·부항·추나·한약의 최근 90일 문헌을 Europe PMC 공개 API에서 매주 수집합니다.
분야마다 최신 최대 10건이며 전체 문헌을 포괄하지 않습니다. API 키, 유료 AI API,
외부 Python 패키지는 사용하지 않습니다. 영어 검색 중심이므로 한국어 문헌 누락이 가능합니다.

## 실행

Python 3.12 이상에서:

```sh
python -m unittest discover -s tests -v
python research.py --limit 10
```

결과는 `results/report.md`와 `results/report.json`에 저장됩니다.
GitHub Actions는 매주 월요일 오전 6시 17분(한국 시간)에 예약 실행되며 지연될 수 있습니다.
Actions 탭의 Free literature monitoring에서 수동 실행도 가능합니다.
실행 결과는 7일간 artifact로 보관됩니다. 장기 학습용 데이터 저장은 아직 없습니다.

## 무료 운영 조건

공개 저장소의 표준 GitHub-hosted Linux runner를 사용하는 구조입니다.
비공개 저장소는 계정의 포함 사용량을 확인하고 유료 초과 사용을 허용하지 마세요.
저장소 공개 여부는 이 코드가 변경하지 않습니다. 비공개 저장소에서는 작업을
자동으로 건너뛰어 실행량 과금을 방지합니다. 외부 API 정책과 GitHub 요금은 변경될 수 있습니다.
작업은 최대 5분, 결과는 7일 보관으로 제한됩니다. 별도 서버는 필요하지 않습니다.

## 현재 기능과 연구 확장

현재 구현은 자동 문헌 모니터이며 자율 의학 AI가 아닙니다.
논문 출판 유형을 저장하지만 효과, 근거 수준, 철회 여부는 자동 판단하지 않습니다.
신규 가설 생성·자기 학습·가상 실험·고전 연결은 구현되지 않았습니다.
실제 데이터를 이용해 검증한 모델 없이 임상 결과를 생성하지 않습니다.

고전은 이용 권한이 확인된 원문을 확보한 후 판본·편명·문장 식별자와 함께
등록해야 합니다. 고전 주장, 현대 관찰, AI 가설, 시뮬레이션 예측은 별도로 관리합니다.
후속 확장에서는 공개 근거 데이터 축적, 전문가 검토, 무료 로컬 모델의 자원 평가,
실제 데이터로 평가한 분야별 실험 모델 연결이 필요합니다.
미검증 조합은 연구 후보이며 환자 치료 지시로 사용하지 않습니다.
